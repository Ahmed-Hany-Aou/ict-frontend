2. Syntax Foundations 03 / 10

Comparison Operators (Relational Logic)

Every condition produces a Boolean value: either True or False

Operator Meaning Python Example Evaluates To
== Equal to 5 == 5 True
!= Not equal to role != "admin" True (if role is user)
> and >= Greater than / Greater or equal score >= 50 True (if score is 75)
< and <= Less than / Less or equal temp <= 37.5 True (if temp is 36.8)
⚠️ GOLDEN RULE FOR STUDENTS: = is for Assignment (giving a variable a value), while == is for Comparison (checking equality)!

3. One-Way Decision 04 / 10

The Single-Way Branch: if Statement

Executes a block of code ONLY when the condition is True

  • 1
    Condition Check: Python tests the expression following the if keyword.
  • 2
    Colon (:): Required at the end of the line to introduce the body.
  • 3
    Indentation (4 Spaces / Tab): Crucial in Python — defines which code belongs inside the condition.
  • 4
    Sequential Continuation: Any unindented line runs regardless of the condition.
temperature_check.py Python 3
# Medical thermometer alert
temp = 38.5

if temp > 37.5:
    print("⚠️ Alert: High temperature detected!")
    print("Please consult a physician.")

print("Diagnostic complete.")
Terminal Output
⚠️ Alert: High temperature detected!
Please consult a physician.
Diagnostic complete.

4. Two-Way Decision 05 / 10

The Two-Way Branch: if...else Statement

Guaranteed execution: either Branch A (True) OR Branch B (False)

The else block acts as the fallback. It executes only when the if condition evaluates to False.
  • ✓
    No Condition for Else: The else keyword NEVER takes an expression.
  • ✓
    Mutual Exclusivity: Exactly ONE block executes — never both, never neither.
license_check.py Python 3
# Driving License Age Verification
age = 16

if age >= 18:
    print("✅ Eligible for Driver's License.")
else:
    print("❌ Underage: Must be at least 18 years old.")
Terminal Output
❌ Underage: Must be at least 18 years old.

5. Multi-Way Decision 06 / 10

Multi-Way Branch: if...elif...else

Testing multiple mutually exclusive conditions in sequential priority

elif stands for Else If. It allows us to chain multiple conditions together.
  • ⚡
    Top-to-Bottom Evaluation: Python checks each condition in order.
  • ⚡
    First-Match Exit: Once a condition evaluates to True, Python executes its body and skips all remaining elif and else blocks!
grading_system.py Python 3
score = 85

if score >= 90:
    grade = "A+ (Excellent!) 🏆"
elif score >= 75:
    grade = "B (Very Good) 🌟"
elif score >= 50:
    grade = "C (Passed) 👍"
else:
    grade = "F (Needs Revision) 📚"

print(f"Student Result: {grade}")
Terminal Output
Student Result: B (Very Good) 🌟

6. Debugging & Mastery 07 / 10

Common Student Traps & How to Avoid Them

Watch out for these 3 syntax & logic pitfalls on exams and in real code

🚫

1. Single '=' Error

Writing if x = 10: causes a SyntaxError because = is for assignment.

Fix: if x == 10:
🚫

2. Missing Colon (:)

Forgetting the colon at the end of the if, elif, or else header.

Fix: if condition:
🚫

3. Range Order Trap

Placing score >= 50 before score >= 90 will catch A+ students as C grades!

Fix: Check largest first
💡 TEACHING TIP: Consistent 4-space indentation is how Python builds code hierarchies without curly braces {}!
