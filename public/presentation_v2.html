كيف يتخذ الإنسان والكمبيوتر القرارات؟

التدفق التتابعي (Sequential Flow): الكمبيوتر ينفذ الأوامر سطراً بعد سطر دون تفكير.
التدفق الشرطي (Conditional Flow): يمنح البرنامج "عقلاً" لتقييم البيانات واختيار المسار المناسب.
🧠 تفكير الإنسان (Human Mind)

تستقبل حواسك مدخلات ➔ عقلك يحلل الموقف ➔ تتخذ قراراً:
"إذا كانت إشارة المرور حمراء، أضغط على الفرامل؛ وإلا أكمل طريقي."

💻 تفكير الكمبيوتر (Computer Logic)

البرنامج يستقبل بيانات (Variables) ➔ يختبر الشرط (True / False) ➔ ينفذ الأوامر التابعة له:
if light == 'RED': stop_car() else: drive()

🚇 بوابة المترو الذكية

فحص الرصيد: لو الرصيد كافي يفتح البوابة، لو غير كافي يرفض.

if balance >= 10: open_gate()
📱 فوري ومحافظ الكاش

التحقق من الرصيد قبل تنفيذ عملية السحب أو دفع الفاتورة.

if wallet >= bill: pay_bill()
🚗 رادار السرعة الذكي

فحص سرعة السيارة: إذا تجاوزت 120 كم/س يتم تسجيل مخالفة فورية.

if speed > 120: log_fine()
القاعدة الذهبية: المدخلات ➔ تقييم الشرط (صح / خطأ) ➔ اتخاذ الإجراء المناسب Page 2
⚙️ محرك المقارنة (Decision Engine) 03 / 11

تشريح الشرط: كيف يسأل الكمبيوتر؟ (Comparison Operators)

الشرط البرمجي هو مجرد سؤال نعم/لا إجابته حصرياً إما True أو False (Boolean).
المعامل (Operator) السؤال المنطقي الذي يسأله مثال تطبيقي النتيجة المنطقية
== هل الطرفان متساويان تماماً؟ score == 100 True (لو الدرجة 100)
!= هل الطرفان مختلفان (لا يساوي)؟ user != 'admin' True (لو مستخدم عادي)
> و >= هل أكبر من (أو يساوي)؟ marks >= 50 True (حد النجاح في مصر)
< و <= هل أصغر من (أو يساوي)؟ balance <= 0 False (لو الحساب به رصيد)
💡 فارق مفاهيمي جوهري: علامة = الواحدة وظيفتها تخزين قيمة في متغير، بينما علامة == المزدوجة وظيفتها طرح سؤال مقارنة!
تفكير منطقي: الشرط لا يقبل إلا احتمالين لا ثالث لهما: True أو False Page 3
🔀 التفرع الأحادي (1-Way Selection) 04 / 11

التفرع الأحادي: جملة الشرط البسيطة (if Statement)

المفهوم: تنفيذ أمر معين فقط وحصرياً إذا تحقق الشرط (True). إذا لم يتحقق الشرط (False)، يتجاهله البرنامج تماماً ويكمل مساره الطبيعي.
📊 خريطة التدفق المعيارية (Flowchart)
fever_check.py تطبيق بايثون
# فحص درجة حرارة المريض temp = 38.8 if temp > 37.5: print("⚠️ تنبيه: حرارة مرتفعة!") print("اكتمل الفحص.")
💻 مخرجات الشاشة (Terminal)
⚠️ تنبيه: حرارة مرتفعة! اكتمل الفحص.
قاعدتان نحويتان: 1. النقطتان (:) في نهاية سطر الشرط | 2. المسافة البادئة (Indentation) لتمييز الأوامر التابعة للشرط Page 4
🔀 التفرع الثنائي (2-Way Selection) 05 / 11

التفرع الثنائي: الاختيار بين بديلين (if...else)

المفهوم (التنافي المنطقي): البرنامج أمام مفترق طرق ذي مسارين حصريين. ينفذ المسار الأول إذا تحقق الشرط (True)، أو ينفذ المسار البديل تلقائياً إذا لم يتحقق (False).
📊 خريطة مسار استخراج رخصة القيادة
license.py تطبيق بايثون
age = 17 if age >= 18: print("✅ مبروك: مؤهل للرخصة.") else: print("❌ عذراً: السن غير قانوني.")
💻 مخرجات الشاشة (Terminal)
❌ عذراً: السن غير قانوني.
ملاحظة مفاهيمية: كلمة 'else' لا تأخذ شرطاً، لأنها تمثل المتمم التلقائي لجميع الحالات الأخرى Page 5
🔀 التفرع المتعدد (Multi-Way Selection) 06 / 11

التفرع المتعدد: سلم التقييم المتسلسل (if...elif...else)

قانون التطابق الأول (First Match Wins): يفحص الكمبيوتر الشروط بالترتيب من الأعلى للأسفل. أول شرط يتحقق (True) ينفذ أمره فوراً ويتجاهل باقي الشروط!
📊 خريطة تقييم درجات الثانوية العامة
grades.py تطبيق بايثون
score = 88.5 if score >= 85: print("امتياز (Excellent) 🌟") elif score >= 75: print("جيد جداً") else: print("مقبول / دور ثان")
💻 مخرجات الشاشة (Terminal)
امتياز (Excellent) 🌟
أهمية الترتيب: يجب ترتيب الشروط من الأعلى للأدنى لضمان عدم حجب التقديرات العليا Page 6
🔗 الربط المنطقي (Logical Operators) 07 / 11

الربط المنطقي وجدول الحقيقة الكامل (and, or, not)

في الحياة العملية، يتطلب اتخاذ القرار التحقق من أكثر من معيار في نفس اللحظة (مثل: معدل مرتفع و عدم وجود مخالفات).
المعامل التعبير المنطقي النتيجة التفسير المنطقي
and (معاً) True and True True ✅ صحيح لأن الشرطين تحققا معاً
and (معاً) True and False False ❌ خطأ لأن أحد الشرطين لم يتحقق
or (أو) True or False True ✅ صحيح لأن شرطاً واحداً يكفي!
or (أو) False or False False ❌ خطأ لأن كلا الشرطين غير متحققين
not (نفي) not True False ❌ يعكس الصواب إلى خطأ والعكس
scholarship.py تطبيق بايثون
# شروط المنحة الجامعية gpa = 3.8 has_violations = False # يجب تحقق الشرطين معاً (and) if gpa >= 3.7 and not has_violations: print("🎉 مبروك: قبول المنحة الكاملة!")
💻 مخرجات الشاشة (Terminal)
🎉 مبروك: قبول المنحة الكاملة!
ملخص القواعد: 'and' تتطلب تحقق الكل | 'or' يكفيها تحقق واحد | 'not' تعكس النتيجة المنطقية Page 7

⚡ التفكير التفاعلي (Classroom Challenge) 09 / 11

تحدي التتبع المنطقي: توقع المخرج البرمجي!

تتبع قيم المتغيرات x = 10 و y = 5 خطوة بخطوة لمعرفة أي رسالة سيتم طباعتها:
quiz_challenge.py تحدي الفصل
x = 10 y = 5 if x > 8 and y > 6: print("الخيار A") elif x > 8 or y > 6: print("الخيار B") else: print("الخيار C")
A الخيار A (خطأ: لأن y > 6 غير صحيح، والـ and تتطلب صحة الاثنين)
B الخيار B (الإجابة الصحيحة ✅)
x > 8 صحيحة وتحقق الـ 'or'
C الخيار C
توجيه تربوي: ناقش مع الطلاب لماذا نجح الخيار B رغم أن y ليست أكبر من 6 (بسبب مرونة المعامل or) Page 9
💼 التطبيق الهندسي الواقعي 10 / 11

دراسة حالة برمجية: نظام حساب الخصم والشحن الذكي (فوري)

الموقف: عميل يشتري بقيمة 650 ج.م. تمنحه المنصة شحناً مجانياً إذا تجاوزت الفاتورة 500 ج.م مع استخدام كوبون 'EGYPT2026'.
1️⃣ المدخلات (Data)
cart_total = 650 EGP
promo = "EGYPT2026"
2️⃣ تقييم الشرط المركب (Logic)
القيمة >= 500 (True) AND الكوبون مطابق (True)
➔ النتيجة النهائية: شحن مجاني (توفير 50 ج.م)
fawry_checkout.py تطبيق بايثون
cart = 650 promo = "EGYPT2026" shipping = 50 if cart >= 500 and promo == "EGYPT2026": shipping = 0 print("🎉 تم تطبيق الشحن المجاني!") print(f"إجمالي الفاتورة: {cart + shipping} ج.م")
💻 مخرجات الشاشة (Terminal)
🎉 تم تطبيق الشحن المجاني! إجمالي الفاتورة: 650 ج.م
