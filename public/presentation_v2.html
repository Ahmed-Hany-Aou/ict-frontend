Why Do We Need Decision Making in Software?

By default, computers execute code sequentially line-by-line. Conditional Statements allow software to evaluate live data and dynamically choose different execution branches.
⚡ Golden Formula: Decision = (Input Data) ➔ [Condition Evaluation: True/False] ➔ (Action Execution)
🚇 Cairo Metro Turnstile

Checks Smart Card balance. Opens the gate only if credit covers the trip fare.

if card_balance >= 10:
    open_turnstile()
📱 Fawry / Vodafone Cash

Validates electronic wallet balance before processing bill payments or transfers.

if wallet >= bill_amount:
    transfer_funds()
🚗 Smart Toll Highway Gate

Scans vehicle electronic RFID tag on Cairo-Alex Desert Road to lift gate barrier.

if rfid_tag_valid == True:
    lift_barrier()

Boolean Expressions & Comparison Operators

A Condition is an expression that Python evaluates to a Boolean value: strictly True or False.
Operator Meaning Example Expression Evaluation Result
== Equal to score == 100 True (if score is 100)
!= Not Equal to user_role != 'admin' True (if user is guest)
> and >= Greater than / Greater or Equal student_marks >= 50 True (Passing Egyptian threshold)
< and <= Less than / Less or Equal wallet_balance <= 0 False (if wallet has funds)
⚠️ CRITICAL TRAP: Single = is for Variable Assignment (x = 5), while Double == is for Equality Comparison (x == 5)!

Two-Way Branching: The "if...else" Statement

🔀 Multi-Way Ladder 06 / 11

Multi-Way Branching: The "if...elif...else" Chain

Evaluates conditions sequentially from top to bottom. The first condition that evaluates to True runs, and all subsequent branches are skipped immediately!
📊 Thanaweya Amma Grading Flow
thanaweya_grading.py Python 3
score = 88.5 if score >= 85: grade = "Excellent (امتياز) 🌟" elif score >= 75: grade = "Very Good (جيد جداً)" elif score >= 65: grade = "Good (جيد)" elif score >= 50: grade = "Pass (مقبول)" else: grade = "Fail (راسب) - Summer Retake" print(f"Evaluation: {grade}")
💻 Terminal Output
Evaluation: Excellent (امتياز) 🌟
Priority Rule: Order conditions from strictest/highest to lowest Page 6
🔗 Compound Logic 07 / 11

Logical Operators: Combining Compound Conditions

Use Logical Operators (and, or, not) to evaluate multiple criteria in a single decision.
Operator Logic Rule Truth Condition
and Conjunction Returns True ONLY if BOTH conditions are True.
or Disjunction Returns True if AT LEAST ONE condition is True.
not Negation Inverts Boolean state (True ➔ False).
🔢 Precedence Order: not evaluates first, then and, then or.
scholarship_check.py Python 3
# Cairo STEM University Scholarship gpa = 3.8 activities = 92 has_violations = False if (gpa >= 3.7 and activities >= 85) and not has_violations: print("🎉 100% Full Scholarship Awarded!") else: print("Standard Admission Track.")
💻 Terminal Output
🎉 100% Full Scholarship Awarded!
Always use parentheses for clear compound expressions: (A and B) or C Page 7

Common Traps, Debugging & Pro Tips

Mastering these 3 common student pitfalls guarantees zero syntax and logic errors in Python exams and projects:
❌ Trap 1: Single '=' in if

Assigning a variable instead of comparing equality throws SyntaxError.

❌ if x = 10:
✅ if x == 10:
❌ Trap 2: Inverted elif Order

Placing loose condition before strict condition captures all cases early.

❌ if score >= 50 (First!)
✅ if score >= 85 (First!)
❌ Trap 3: Missing Colon / Indent

Forgetting : or mixing tabs and spaces causes IndentationError.

❌ if score > 50
✅ if score > 50:

Case Study: Fawry E-Commerce Smart Checkout

Scenario: A customer in Cairo buys electronics worth 650 EGP. Free Delivery is awarded if order >= 500 EGP AND promo code is 'EGYPT2026'. Otherwise, standard delivery is 50 EGP.
1️⃣ Input Data
cart_total = 650
promo = "EGYPT2026"
city = "Cairo"
2️⃣ Compound Condition
cart_total >= 500 (True)
AND promo == "EGYPT2026" (True)
➔ Overall: TRUE
3️⃣ System Action & Output
✅ Free Delivery Applied (Saved 50 EGP).
💳 Final Invoice: 650 EGP
fawry_checkout.py Python 3
cart_total = 650 promo_code = "EGYPT2026" delivery_fee = 50 if cart_total >= 500 and promo_code == "EGYPT2026": delivery_fee = 0 print("🎉 Promo Applied: Free Delivery!") final_amount = cart_total + delivery_fee print(f"Total Amount Due: {final_amount} EGP")
💻 Terminal Output
🎉 Promo Applied: Free Delivery!
Total Amount Due: 650 EGP
