Why Do We Need Decisions in Code?

In real life: "IF it rains, I take an umbrella. ELSE, I walk freely."
In software, Conditional Statements give programs the exact same superpower: checking data before taking action!
⚡ The Simple Formula: Input Data ➔ Ask a Yes/No Question (True/False) ➔ Run Matching Action
🚇 Cairo Metro Gate

Checks your Smart Card balance. If you have enough credit, it opens the turnstile!

if balance >= 10:
    open_gate()
📱 Fawry / Mobile Cash

Checks your wallet before approving a bill payment or mobile balance recharge.

if wallet >= bill:
    pay_bill()
🎮 Video Game Logic

When the player's health drops to 0, the game triggers the Game Over screen.

if health <= 0:
    game_over()

⚙️ The 6 Comparison Questions 03 / 11

Comparison Operators (Asking Questions in Code)

A Condition is simply a question Python answers with strictly True (Yes) or False (No).
Operator Question it Asks Example Expression Evaluation Result
== Is it equal to? score == 100 True (if score is 100)
!= Is it NOT equal to? user != 'admin' True (if guest user)
> and >= Is it greater (or equal)? marks >= 50 True (Pass Egyptian threshold)
< and <= Is it less (or equal)? wallet <= 0 False (if wallet has money)
💡 Remember: Single = is for giving a value (x = 5), while Double == is for asking a question (x == 5)!

🔀 1-Way Decision 04 / 11

1-Way Decision: The "if" Statement

Runs the code block ONLY IF the condition is True. If False, it simply skips it.
📊 Visual Flowchart
fever_check.py Python 3
# Temperature screening temperature = 38.8 if temperature > 37.5: print("⚠️ Warning: High temperature!") print("Please consult a doctor.") print("Check completed.")
💻 Terminal Output
⚠️ Warning: High temperature! Please consult a doctor. Check completed.
2 Key Rules: 1. Colon (:) at end of if line | 2. Indent 4 spaces inside the block Page 4
🔀 2-Way Decision 05 / 11

2-Way Decision: The "if...else" Statement

Gives you a choice between two paths: Path A (if condition is True) OR Path B (if condition is False). Exactly ONE path will run!
📊 Visual Flowchart
driving_license.py Python 3
# License Eligibility age = 17 if age >= 18: print("✅ Approved: Eligible for license.") else: wait_years = 18 - age print("❌ Rejected: Underage applicant.") print(f"Please reapply in {wait_years} year(s).")
💻 Terminal Output
❌ Rejected: Underage applicant. Please reapply in 1 year(s).
Key Rule: 'else' takes NO condition because it is the automatic fallback Page 5
🔀 Multi-Way Ladder 06 / 11

Multi-Way Decision: The "if...elif...else" Ladder

Evaluates conditions from top to bottom. The first condition that is True runs, and Python immediately skips the rest!
📊 Egyptian High School Grading
grades.py Python 3
score = 88.5 if score >= 85: grade = "Excellent (امتياز) 🌟" elif score >= 75: grade = "Very Good (جيد جداً)" elif score >= 65: grade = "Good (جيد)" elif score >= 50: grade = "Pass (مقبول)" else: grade = "Fail (راسب) - Summer Retake" print(f"Grade: {grade}")
💻 Terminal Output
Grade: Excellent (امتياز) 🌟
Order Matters: Always arrange conditions from highest to lowest Page 6
🔗 Combining Conditions 07 / 11

Logical Operators & The Complete Truth Table

Use and, or, and not to combine multiple checks in a single statement.
Operator Expression Evaluation Why?
and True and True True ✅ Both sides are True
and True and False False ❌ One side is False
or True or False True ✅ At least one side is True!
or False or False False ❌ Both sides are False
not not True False ❌ Inverts True to False
scholarship.py Python 3
# University Scholarship Check gpa = 3.8 has_violations = False # Both conditions must be met: if gpa >= 3.7 and not has_violations: print("🎉 Full Scholarship Awarded!") else: print("Standard Admission Track.")
💻 Terminal Output
🎉 Full Scholarship Awarded!
Summary: 'and' needs ALL True | 'or' needs ANY True | 'not' flips the result Page 7
🛠️ Pro Tips 08 / 11

Top 3 Traps to Avoid (Common Student Mistakes)

Avoid these 3 common pitfalls to ensure your code runs cleanly without errors:
❌ 1. Single '=' inside if

Assigning a value instead of comparing throws a SyntaxError.

❌ if x = 10:
✅ if x == 10:
❌ 2. Wrong elif Order

Putting a loose condition first triggers too early and breaks the grading!

❌ if score >= 50 (First!)
✅ if score >= 85 (First!)
❌ 3. Missing Colon ':'

Forgetting the colon at the end of the if line causes an error.

❌ if score > 50
✅ if score > 50:

💼 Real-World Application 10 / 11

Case Study: Fawry Smart Promo Checkout

Scenario: A customer buys goods worth 650 EGP. Free Delivery is awarded if order >= 500 EGP AND promo code is 'EGYPT2026'.
1️⃣ Input Data
cart_total = 650
promo = "EGYPT2026"
2️⃣ Compound Check (and)
cart >= 500 (True) AND promo match (True)
➔ Both are True: Free Delivery!
fawry_checkout.py Python 3
cart_total = 650 promo = "EGYPT2026" delivery_fee = 50 if cart_total >= 500 and promo == "EGYPT2026": delivery_fee = 0 print("🎉 Free Delivery Applied!") total = cart_total + delivery_fee print(f"Final Bill: {total} EGP")
💻 Terminal Output
🎉 Free Delivery Applied! Final Bill: 650 EGP
